Course conventions reflected here: descriptive variable names; no `break`; word-scanning exercises avoid `split()` and define letters as ASCII a–z/A–Z. Automated input/output tests demonstrate behavior; unless a checker explicitly validates syntax, passing them alone does not establish compliance with every requested implementation technique.

The source's module notes contain reversed comments for floor/ceil even though their numeric output is correct. Its temperature practice contains a Fahrenheit-to-Celsius formula typo. This app uses verified Python behavior and the correct conversion `(fahrenheit - 32) * 5 / 9`. Functions are included because the user explicitly includes them and the current repository contains both function lectures and function questions in the midterm review; an older sentence in the module notes says functions would be after the first midterm. The Oct 27, 2026 date comes from the user, not a verified source calendar.

The source README restricts reuse outside class study. This app links the original course resources and supplies original study explanations/exercises; it does not redistribute the lecture assets or long passages of the notes.
